# Code of Conduct

JurisDev Kenya is committed to providing a welcoming and respectful environment for everyone.

We expect members to:

- Treat others with respect.
- Welcome different perspectives.
- Provide constructive feedback.
- Focus discussions on ideas rather than individuals.
- Help create an inclusive and collaborative community.

The following behaviour is unacceptable:

- Harassment
- Personal attacks
- Discrimination
- Intimidation
- Deliberate disruption

If you experience or witness behaviour that violates this Code of Conduct, please contact the organization maintainers.

By participating in JurisDev Kenya, you agree to follow these principles.
