# Contributing to JurisDev Kenya

Thank you for your interest in contributing to JurisDev Kenya.

We welcome contributions from lawyers, software developers, researchers, designers, students, policymakers, technical writers, and anyone interested in advancing legal technology.

## Ways to Contribute

You can contribute by:

- Developing software
- Improving documentation
- Conducting legal or technical research
- Reviewing legal content
- Reporting bugs
- Suggesting new features
- Participating in discussions
- Helping with community initiatives

## Before You Start

Before starting significant work, please:

1. Search existing issues and discussions.
2. Open a discussion if you'd like to propose a new idea.
3. Wait for feedback before beginning large features.

## Development Workflow

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Commit your work with clear commit messages.
5. Open a Pull Request.

## Code Standards

Please:

- Write clear, maintainable code.
- Document new functionality.
- Keep pull requests focused on a single change.
- Follow repository-specific coding conventions.

## Community

Please be respectful and constructive in all discussions.

We value collaboration, curiosity, and professionalism.
